# Simple Interest Calculator

## Project Description
The Simple Interest Calculator is a simple project that calculates the interest earned on a principal amount based on the rate of interest and time period.

## Formula
Simple Interest = (Principal × Rate × Time) / 100

## Input
- Principal amount
- Rate of interest (annual percentage)
- Time period (in years)

## Output
- Calculated simple interest
- Total amount (Principal + Simple Interest)

## Technology Used
- Bash scripting
- Git and GitHub

## Usage
Run the `simple-interest.sh` script in a Bash terminal and enter the principal amount, rate of interest, and time period when prompted.

## Project Goal
To demonstrate basic Bash scripting, user input handling, arithmetic operations, and GitHub repository management.
